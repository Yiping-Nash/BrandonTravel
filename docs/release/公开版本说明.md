# 求职展示公开版本说明

## 产品

采用用户提供的中文展示结构作为README首页，保留英文入口。放入实际人工编辑GIF、真实模型/MCP提案确认GIF、自然成形计划主视觉及10分钟重叠截图。原始三段视频和可检查证据分别链接；Built、Experimental、Product Vision明确区分。不提供公网业务后端或匿名模型入口。

## 验收

三段录屏已完成实际UI操作与正式API读回。最终Agent场景确认前计划不变，确认后applied，revision 1→2，只改授权活动；重叠10分钟明确可见。确认点击由脚本执行，非完整真人验收。共6模型请求，首轮上下文失败及第二轮录制断言错误均保留。GIF源于原视频，约4fps，不添加伪造步骤。

README及主要文档的本地链接存在；WebM可播放、解码和寻址，GIF可解码且保留实际时序。新发布快照不携带旧Git历史，发布文件与来源历史做常见凭据模式检查，未发现命中。这不是对所有可能秘密格式的绝对保证。账号、数据库、.runtime、.tools、node_modules及私人协作文档不在提交范围。

## 技术

代码基线d94769d，旅行Domain/Agent业务源码保持该基线。新仓库为经过筛选的发布快照，不改写原仓库历史。演示导入允许选择公开候选数据，录制脚本可通过WEB_URL指定本机地址。保留LICENSE、UPSTREAM及依赖许可元数据；无新增生产依赖、模型框架或外部服务。没有执行公网部署。

## 怎么启动项目

先按README安装本地依赖并初始化数据库，然后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/local-db.ps1 start
$env:TRAVEL_FACTS_ALLOW_NETWORK='false'
node scripts/local-start.mjs
```

默认网页http://localhost:4331/，API http://127.0.0.1:4332/。最后一条启动前后端，需保持终端打开；停止它不会停止数据库。全新机器安装未独立验证。不配置模型可查看与编辑计划；配置模型后发送聊天会产生实际调用。

只看历史静态演示：node scripts/demo-preview.mjs，http://127.0.0.1:4335/，无需数据库/后端。新录屏在 /v2/01-creating.webm、/v2/02-formed.webm、/v2/03-collaborating.webm。
