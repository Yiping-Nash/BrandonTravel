# R1 independent code review

Date: 2026-10-26. Reviewer: independent Codex context `r1_review`; this is an AI engineering review, not human recommendation-quality approval. Human product/quality review: **Pending**.

Scope: actual uncommitted R1 changes in research contracts, source adapters, Deep Agents composition, CLI, budget ledger and LangSmith evaluation. No paid API calls were made by this reviewer. No framework internals or product files were edited by the reviewer.

## Findings, highest severity first

1. **P1 — SDK retries bypassed model-attempt accounting — fixed and verified.** Original `apps/api/agent/research.py:94–95` copied `max_retries=0` onto an already-constructed model from `_make_model()`. The underlying OpenAI clients retained `max_retries=1`, so one counted request could issue two provider attempts. A no-network dummy-key reproduction printed public field `0`, sync client `1`, async client `1`. The implementation now passes retries at model construction (`research.py:102–103`, `service._make_model`). Independent recheck: both actual clients report `0`.

2. **P2 — Changing working directory reset the shared iteration budget — fixed and verified.** Original `evaluation/research_budget.py:7` defaulted to a relative `data/iteration2/budget.sqlite3` while CLI inputs/output paths were repository-absolute. Running from another directory created a new ledger. Default now anchors to repository root; inspected default is absolute. Explicit temporary paths remain supported for isolated tests.

3. **P2 — Unverified traces could receive a passing deterministic evaluation — fixed and verified.** Original `evaluation/research_evaluate.py:10–25` omitted `traceVerified`; a synthetic result with `traceVerified=False` passed every check. A `trace_verified` check now rejects it. No-network recheck passed.

4. **P2 — Aggregate summary mixed evaluation cohorts — fixed and inspected.** `evaluation/research_cli.py:115–147` now separates batch, tool mode, model mode, architecture and source fingerprint; formal gates only consider live evaluation and group by experiment. Exactly 18 cases × three runs, >=51 passes and >=2 per case are required, with verified traces. Human review and R2 acceptance remain Pending.

5. **P2 — Missing usage appeared as full-task cost — fixed and inspected.** `evaluation/research_cli.py:90–95` now emits `costCompleteness`, a known-usage lower bound and null full-task estimate if usage is incomplete. The ledger retains the original reservation for unknown usage rather than retroactively repricing old attempts.

6. **P1 — Official evaluation roots were created before quota reservation — fixed and verified.** The official `aevaluate()` runner wraps the target in `traceable` before entering it. Reserving only inside `execute()` allowed an exhausted quota to create unreserved failed target traces. A public `@traceable` probe with an in-memory client reproduced `trace_created → budget_rejected → trace_updated`. `evaluate_dataset()` now reserves 56 batch trace slots before calling the SDK, in addition to conservative per-task slots. Independent temporary-ledger verification: slots exist before runner entry; a full 1,000-slot ledger prevents runner entry entirely.

7. **P2 — Reused Dataset content drift was not detected — fixed and verified.** A reused dataset previously needed only 18 examples, even if inputs had been edited. `evaluation/research_evaluate.py` now compares canonical sorted fetched inputs to local fixed briefs. In-memory test with one edited question: `DATASET_CONTENT_CHANGED`, runner not called, zero batch trace slots consumed.

8. **P2 — SQLite connections were not explicitly closed — fixed and verified.** The earlier temporary-ledger verification failed Windows directory cleanup with `WinError 32`. `ClosingConnection.__exit__` now delegates commit/rollback and closes in `finally`. Reviewer-added regression tests retain the connection reference and verify closure after successful commit, a transaction-body exception, and a deferred-constraint failure during commit. They verify commit/rollback results and immediately remove the temporary database without garbage collection.
